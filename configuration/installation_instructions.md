The Olostep MCP server needs an Olostep API key.

1. Create a free account at [olostep.com/auth](https://olostep.com/auth)
2. Copy your API key from the Olostep dashboard
3. Paste it as `olostep_api_key` below

Once configured, the Agent Panel can use these tools: `scrape_website`, `get_webpage_content`, `search_web`, `answers`, `get_website_urls`, `create_map`, `batch_scrape_urls`, `get_batch_results`, `create_crawl`, and `get_crawl_results`.
